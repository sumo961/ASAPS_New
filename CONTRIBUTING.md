# Contributing to ASAPS

Contributions are welcome.

1. Fork the repository and create a branch for your change.
2. Set up and build as described in [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md).
3. Make your change, and add tests for new behaviour.
4. Run the tests for the packages you touched, one package at a time (`npm run test -w @asaps/core`, `-w @asaps/renderer`, `-w @asaps/builder`), plus `npm run type-check` and `npm run lint`.
5. Open a pull request that says what changed and why.

Found a bug or have an idea? [Open an issue](https://github.com/sumo961/ASAPS_New/issues).
